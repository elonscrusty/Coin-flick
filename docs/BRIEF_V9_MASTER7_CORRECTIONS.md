## 3. One coherent art language before adding assets
Use a clean Roblox mining-camp style with deliberate low-poly shapes and restrained surface detail. The first priority is silhouette, proportion, spacing and grounding. The second is material contrast. Small bolts, strips, crates and texture noise come last. An asset count is not a quality target. Every added object must clarify a function, frame a focal point or complete construction.
