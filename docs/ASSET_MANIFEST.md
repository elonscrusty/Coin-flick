uploaded by `ROBLOX_USER_ID=20194281 python3 tools/upload_meshes.py` (Open Cloud Assets API, assetType Model, .glb).
Ids live in art/meshes/uploaded_ids.json and src/shared/MeshIds.luau (0 = not uploaded). At boot
`MeshService` loads each id with InsertService:LoadAsset and puts a MeshPart template named `CT_Rocks_<Name>`
in ReplicatedStorage.Assets. If a template is missing the Part stand-in is used, so offline preview and Studio
without assets still work.

Common: units = studs, front -Z, up +Y, flat normals, vertex colours (COLOR_0, tinted by MeshPart.Color), no UVs or textures,
no animated parts, no LOD (all under 400 tris except the v2 jackhammer, 704), collision: none on the templates (CanCollide/CanQuery/CanTouch false);
pile rocks are switched back to queryable + collidable when cloned. Assembly: GeodeModel.build = shell + bed + crystals;
tools = invisible Grip part + mesh welded at the file origin.

## World placement (measured; Master Prompt 8 sections 5, 13, 23)

Every placed world asset in the lobby and one hunt arena, measured from the real builders by the `placement` preview scene
(`bash tools/preview/run_scene.sh placement --set manifest=on`, rows `[asset]`), which also audits them numerically in
`tools/run_regressions.sh` (floating / buried, clipping, z-fighting, routes, collision, CameraIgnore / ray policy).
Size = bounding box as placed (studs, X x Y x Z in the model's pivot frame); Bottom = lowest point above (+) or below (-)
the floor under it. Collision: kit meshes never collide; a prop that can be bumped into carries an invisible blocker
(`KitPlace.blocker` / `KitPlace.solidify`), shown here when it is a child of the model or named when it is a sibling.
Decor (visible, non-colliding) is CameraIgnore, CanQuery false and CanTouch false everywhere (`KitPlace.decorPolicy` in
the lobby, `tagCameraIgnore` in the arena); functional parts (prompts, signs, plates, pads, floors) keep their queries.
